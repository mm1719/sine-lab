容易搞混的地方sin(2x − π)，到底往右移多少？＋
sin(2x − π) = sin[2(x − π/2)]

先把 x 的係數 2 提出來，才看得出括號裡的位移。相對於 sin(2x)，這條曲線向右移 π/2（90°），週期是 π（180°）。若寫成 A sin(Bx + C) + k，水平位移就是 h = −C/B（B ≠ 0）。

從一個小變化開始。

  1. 選一個實驗。前四關各改一個參數，最後一關可同時調整四個。
  2. 先猜，再拖。拖動滑桿或圖上的綠色控制點，和灰色原始曲線比較。滑桿可用方向鍵微調。
  3. 看看數字。公式、振幅、週期與中線會同步更新。弧度／角度可隨時切換。
  4. 完成一個小任務。按「檢查我的圖形」得到回饋；自由實驗中，試著與橘色曲線重合。
給老師的小提示：先用「播放變化」建立直覺，再讓學生自己操作並說明原因。每關的參數會暫時保留，重新整理頁面後回到初始狀態。

本頁專注 B > 0 的水平伸縮；B = 0 時變成常數，B < 0 會再加入水平翻轉。
