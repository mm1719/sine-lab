# Sine Lab｜正弦波互動實驗室

用拖曳與圖形，探索正弦函數的平移與伸縮。適合家教教學與課後自主練習。

## 互動內容

- 四個獨立實驗：垂直伸縮 A、水平伸縮 B、水平平移 h、垂直平移 k。
- 綜合實驗：同時調整四個參數，與目標曲線比對。
- 支援滑桿、圖上拖曳、原始曲線比較、輔助線、縮放與動畫。
- 弧度／角度切換、即時公式、振幅、週期與中線。
- 15 個小任務，附提示、檢查與觀察重點。
- 手機、平板與桌面版面；不需要登入或安裝。

## GitHub Pages

在儲存庫的 Settings → Pages 中，選擇 Deploy from a branch，分支 master、目錄 /(root)，再儲存。

所有網頁檔案都放在根目錄，並以相對路徑載入；`.nojekyll` 讓 GitHub Pages 直接發布靜態檔案。不需要額外套件或建置步驟。

## 本機執行與驗證

使用任意靜態 HTTP 伺服器開啟此目錄。例如：

```sh
python3 -m http.server 8000
```

再以瀏覽器開啟 localhost:8000。ES 模組需要 HTTP 伺服器，請勿直接以 file:// 開啟 index.html。

數學檢查：`node --test tests/math.test.js`。

內部以弧度計算；切換角度單位只改變顯示。為聚焦水平伸縮，本教材取 B > 0。A = 0 時為常數函數，沒有基本週期。所有參數只保留在當前頁面，重新整理後重設。
